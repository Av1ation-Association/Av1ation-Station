The `0.1.0-rc.3` pre-release ships unsigned Windows and Linux installers and an ad-hoc signed macOS build. Start with the bundled build: it includes FFmpeg, VapourSynth, MKVToolNix, the encoders, the scene model, and the quality metrics, so there is nothing else to install.

## Check the toolchain

Open **Settings → Dependencies**. Each row names a capability, the provider the application found, and where that provider comes from. Choose **Bundled**, **System** for an executable already on `PATH`, or **Custom** to point at a specific file.

<LiveSample kind="toolchain" />

The system build starts without the bundled tools. After installing it, set a provider for every capability your workflow uses and check again. Restart only when a row says a restart is required.

A missing optional encoder removes only that encoder. It does not disable decoding, scene detection, or muxing. A missing required provider blocks only the step that needs it.

Read [Resolve dependencies and add encoder builds](/docs/guides/dependencies) to register an encoder build, or [Missing tools and providers](/docs/troubleshooting/dependencies) when a row stays unavailable.

## Troubleshooting

- **Windows SmartScreen warns about the publisher**: the installer is unsigned. Confirm the download came from the project release page; do not disable system-wide security controls.
- **macOS blocks the app**: the build is ad-hoc signed and not notarised, so Gatekeeper may refuse it. Confirm the download came from the project release page; do not disable system-wide security controls.
- **The installer is blocked by policy**: use the portable build if policy allows it, or build from source. Do not turn off security controls to force the installer to run.
- **A capability is still unavailable**: check the row's source and executable, then check again. The [dependency troubleshooting guide](/docs/troubleshooting/dependencies) explains what each state means.
